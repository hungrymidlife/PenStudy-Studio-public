# 알려진 제한 사항과 검증 체크리스트

- **본 프로젝트는 작업 가능한 소스 초안이지 검증 완료된 배포판이 아닙니다.** 환경에 따라 Tauri Android/Windows 의존성 버전 조정이 필요할 수 있습니다.
- S펜은 Android WebView의 PointerEvent `pointerType='pen'`과 `pressure`를 사용. 실제 S24 Ultra WebView에서 해당 필드가 전달되는지 확인 필요.
- Android S펜 **물리 버튼/호버/에어 액션 전용 기능은 미구현**. S24 Ultra의 버튼 이벤트는 OS/삼성 정책에 따라 앱 수신이 제한될 수 있으므로 Kotlin 레이어에서 실기기로 검증 필요.
- Android 연결 해제 후 재연결 시 32자리 토큰 재입력 가능. 호스트 IP만 휴대폰에 저장.
- PC 서버는 첫 번째 성공적으로 인증된 한 기기만 입력을 받아들임.
- Wi-Fi 연결은 평문 WS이므로 집 내부 신뢰 LAN에서만 사용. 외부 네트워크 차단과 TLS는 별도 구현 과제.
- 펜 필압은 기본적인 선 두께 보정으로 반영함. 필압 곡선/보정/어플리케이션별 프로파일은 추후.
- Android 화면 미리보기는 되돌리기/저장 시 PC 쪽 그림과 완전히 동기화되지 않으며 초기화될 수 있음. 실제 PC 오버레이가 원본 데이터.
- Android 가로모드에서 화면 좌표 매핑 검증 필요. 휴대폰은 작은 입력면이라 가로모드를 권장.
- 앱은 기본으로 **주 모니터**를 대상으로 함. 다른 모니터/주 모니터 변경 시 위치 재배치가 아직 없음.
- 클립보드 접근/Google Fonts 같은 외부 의존 없는 사용을 지향. 앱 네트워크 접근은 개발서버/로컬 입력 서버로 제한할 것.
- 일부 전체화면 게임, DRM 보호 화면, 고권한 프로그램 위의 투명 오버레이 또는 스크린샷은 작동하지 않을 수 있음.
- F9/F7/F10 글로벌 단축키가 다른 앱과 충돌하면 등록되지 않을 수 있음. Windows 실제 환경에서 점검.
- Android `android init`으로 생성된 템플릿의 Manifest/Gradle 구조는 Tauri 릴리스에 따라 바뀔 수 있으므로 패치 적용 결과를 검사.

## 최소 검증 매트릭스

| 시험 | 기대 결과 | 상태 |
| --- | --- | --- |
| `npm install` | 모든 프런트엔드 의존성 다운로드 | 미실행 |
| `npm run build:web` | TypeScript/Vite 빌드 | 미실행 |
| `npm run desktop` | Windows Tauri 시작 및 오버레이 표시 | 미실행 |
| PC 서버 시작 (USB/로컬) | 127.0.0.1:39871 활성화 | 미실행 |
| Android `tauri android init/dev` | S24 Ultra 앱 실행 | 미실행 |
| PC Wi-Fi 연결 | 토큰 인증 및 S펜 스트로크 전달 | 미실행 |
| F9 | 원본 화면+필기 PNG 캡처 | 미실행 |
| F7/F10 | 실행 취소/전체 지우기 | 미실행 |
| 125%/150% DPI | 좌표 왜곡 없이 필기 | 미실행 |
| 서버 중지 | 즉시 접속 종료 | 미실행 |
