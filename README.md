# PenStudy Studio · Windows 오버레이 + Android S펜 패드

> **갤럭시 S24 Ultra 등의 S펜 기기를 Windows PC의 투명 필기 오버레이 또는 그림 프로그램 입력 장치로 사용하는 프로젝트**
>
> 기술: **Tauri 2 · Rust · React · TypeScript** / 연결: 로컬 WebSocket(USB 또는 Wi-Fi) / 저장: **PNG · 레이어 PSD**

Windows의 주 모니터 위에 필기하고 화면을 캡처하거나, 지원하는 그림 프로그램이 활성화되면 Windows 마우스 입력으로 해당 앱의 캔버스에 그릴 수 있습니다. Photoshop 등에 전달하는 입력은 **필압을 지원하는 Windows Ink 가상 펜이 아닌 마우스 이벤트**입니다. 실제 사용 환경에서의 빌드·입력 호환성은 별도 확인이 필요합니다.

**빠른 링크:** [Windows·Android 빌드](#빌드-및-실행-명령어) · [PC 전역 단축키](#직접-지우개-및-사용자-지정-전역-단축키) · [그림 프로그램 자동 연결](#그림-프로그램-활성-창-자동-연결-및-오버레이-전역-단축키) · [MIT 라이선스](LICENSE) · [서드파티 라이선스](THIRD_PARTY_NOTICES.md) · [오픈소스 공개 전 점검](docs/OPEN_SOURCE_RELEASE_CHECKLIST.md)

## 주요 기능

- **Windows PC:** 주 모니터 투명 필기 오버레이, 개별 레이어 필기·지우기·되돌리기, 펜/지우개 독립 굵기, 필압, 좌우 독립 플로팅 툴바.
- **Android S펜:** 16:9 입력판, QR 페어링, 호버·필압 입력(기기 지원 범위), 모바일 좌우 도구 바.
- **캡처 및 파일:** 전체 화면·드래그 영역·고정 영역 PNG, 편집 가능한 이미지 레이어 PSD. **저장 뒤 필기와 레이어는 자동 삭제되지 않습니다.**
- **단축키:** PNG·PSD, 필기/마우스 전환, 브러시·레이어·지우개 등을 포함한 **26개 동작의 사용자 지정 Windows 전역 단축키**.
- **그림 프로그램:** Photoshop, 그림판, Krita, Paint.NET, Clip Studio Paint, SAI가 **활성 창**일 때 자동 마우스 입력 라우팅(설정에서 끄기 가능).

## 빌드 및 실행 명령어

프로젝트 루트에서 PowerShell 명령을 실행합니다.

```powershell
cd C:\dev\tool\PenStudy-Studio-public
git switch main
git pull origin main
npm ci
```

| 대상 | 명령어 | 기본 결과 |
| --- | --- | --- |
| Windows 개발 실행 | `npm run desktop` | Tauri 개발 창 |
| Windows 설치형 EXE | `npm run desktop:build` | `apps/desktop/src-tauri/target/release/bundle/nsis/` |
| Windows 포터블 EXE | `npm run tauri --workspace=@penstudy/desktop -- build --no-bundle` | `apps/desktop/src-tauri/target/release/penstudy-desktop.exe` |
| Android 개발 실행 | `npm run android:dev` | 연결된 Android 기기 실행 |
| Android 디버그 APK | `npm run android:apk` | `apps/android/src-tauri/gen/android/app/build/outputs/apk/` |
| Android 릴리스 APK | `npm run tauri --workspace=@penstudy/android -- android build --apk` | 별도의 Android 릴리스 서명 설정 필요 |
| 타입 검사 / 테스트 | `npm run typecheck` / `npm test` | 소스 검증 |

- Windows 빌드에는 Rust/MSVC 및 **WebView2 Runtime** 환경이 필요합니다. 포터블 EXE도 WebView2 설치 여부의 영향을 받습니다.
- Android는 **Android Studio, SDK/NDK, JDK, Rust Android 대상, Android 초기화 작업**이 필요합니다. Android 실행/빌드 전에 아래 초기화와 Manifest 설정 절차를 확인하세요.
- 위 경로는 기본 출력 위치이며 운영체제/빌드 옵션·환경에 따라 달라질 수 있습니다. 실제 산출물이 생성되었는지는 빌드 로그로 확인하세요.
- `npm ci`는 잠금 파일과 일치하는 의존성을 설치하며, Android 빌드용 SDK/Gradle 도구까지 대신 설치하지는 않습니다.


## 설치 위치

ZIP을 **`C:\dev\tool`** 에 해제하면 아래처럼 됩니다.

```text
C:\dev\tool\PenStudy-Studio-public\
  START_WINDOWS_DEV.bat
  INIT_ANDROID.bat
  RUN_ANDROID_DEV.bat
  BUILD_ANDROID_DEBUG_APK.bat
  apps\desktop\       Windows Tauri GUI + Rust 브리지/화면 캡처
  apps\android\       Android Tauri GUI + S펜 WebView PointerEvent
  packages\protocol\ 통신 프로토콜
  scripts\           Android Manifest 패치
  docs\              기술·보안·검증 안내
```

## 개발 환경

- Windows 10/11, Node.js 20 이상, Rust 최신 stable (global shortcut 플러그인은 Rust 1.90 이상 요구), Microsoft C++ Build Tools, WebView2.
- Android: Android Studio + Android SDK/NDK + JDK + Rust Android targets. **`adb` 연결**과 **USB 디버깅** 필요.
- 이 GitHub 저장소는 소스 중심입니다. EXE/APK, `node_modules`, Rust `target`, SDK/NDK, Gradle 산출물은 기본적으로 포함되지 않으며 로컬 환경에서 별도로 생성합니다.
- 의존성은 최초 `npm install` 시 다운로드합니다. 특정 Tauri/Rust 조합이 환경에 따라 추가 설정을 요구할 수 있습니다.

## Windows 실행

1. `START_WINDOWS_DEV.bat` 더블클릭 또는 PowerShell에서:

   ```powershell
   cd C:\dev\tool\PenStudy-Studio-public
   npm install
   npm run desktop
   ```

2. GUI가 열리면 네트워크 종류를 선택하고 **입력 서버 시작**.
3. USB를 먼저 쓸 경우 **USB / 로컬 전용**(127.0.0.1), Wi-Fi를 쓸 경우 **같은 Wi-Fi 연결** 선택.
4. 서버 시작 후 나타나는 **32자리 인증 토큰**을 휴대폰 앱에 입력.
5. 주소 확인: Windows에서 `ipconfig` → 실제 사용 중인 Wi-Fi/이더넷 어댑터의 **IPv4 주소** 확인. 예: `192.168.0.12`.
6. Wi-Fi 모드에서는 Windows 방화벽에서 **개인 네트워크만 허용**. 공용 네트워크 예외 등록은 피하세요.

## Android 앱 최초 초기화

Android SDK, JDK, NDK, rustup 설정 후:

1. `INIT_ANDROID.bat` 실행 → `tauri android init` (처음 한 번). 생성되는 `apps/android/src-tauri/gen/android`는 소스 ZIP에 포함하지 않음.
2. **중요:** `scripts/patch-android-manifest.ps1`이 생성된 AndroidManifest.xml에 `INTERNET` 권한 및 **로컬 비암호화 WS 전용** `usesCleartextTraffic=true`를 적용합니다. Android 빌드 전 다시 적용해도 안전하게 동작하도록 작성.
3. 스마트폰에서 개발자 옵션 → USB 디버깅 켜기; PC와 USB 연결 후 승인.
4. `RUN_ANDROID_DEV.bat` 실행 (연결 기기에서 개발 실행).
5. 배포용 서명 APK 생성·배포는 별도 절차. 디버그 APK가 필요하면 `BUILD_ANDROID_DEBUG_APK.bat`에서 `tauri android build --apk --debug` 시도 (환경별 옵션 확인).

### Wi-Fi 연결

- PC와 S24 Ultra를 같은 **신뢰할 수 있는** 사설 Wi-Fi에 연결.
- PC GUI에서 **같은 Wi-Fi 연결** → **입력 서버 시작**.
- 휴대폰의 PC 주소에 `192.168.x.x`처럼 **PC의 IPv4 주소** 입력 (포트는 39871 고정).
- PC 화면의 **세션 인증 토큰** 붙여넣기 → 연결.
- 기기 간 통신이 막히면 공유기의 AP isolation, Windows 방화벽, PC/폰 Wi-Fi 대역을 점검.

### QR 간편 페어링 (Windows ↔ Galaxy S24 Ultra)

1. Windows PenStudy Studio에서 **기기 연결** 메뉴를 연 후 Wi-Fi 또는 USB 모드를 선택하고 **입력 서버 시작**.
2. **Wi-Fi 모드**: PC의 사설 IPv4 주소(예: 192.168.219.103)가 자동 제안됩니다. 여러 네트워크를 사용하면 정확한 PC 주소로 수정하세요.
3. 화면에 표시된 **QR코드**를 Galaxy S24 Ultra의 PenStudy Pad → **PC 페어링 QR 스캔** 버튼으로 스캔.
4. Android 카메라 권한을 처음 한 번 승인. QR 안의 주소 및 세션 토큰이 자동으로 설정되고 연결을 시도합니다.
5. 연결되지 않으면 기존의 **주소/토큰 수동 입력**을 그대로 사용할 수 있습니다.

- Android 카메라 스캔에는 **Tauri Barcode Scanner 네이티브 플러그인**을 사용합니다.
- Windows QR은 **앱 내부에서만 생성**하며 QR 외부 생성 사이트에 토큰을 업로드하지 않습니다.
- QR에는 실제 세션 토큰이 포함되므로 촬영/공유 금지. 서버 중지 후 다시 시작하면 토큰이 바뀌어 기존 QR은 무효화됩니다.
- Wi-Fi는 같은 신뢰할 수 있는 사설 네트워크에서만 사용할 것을 권장합니다. USB는 **ADB reverse tcp:39871 tcp:39871**을 먼저 실행해야 합니다.
- QR을 스캔해도 Android 앱에서 직접 기기와 통신할 수 없는 경우(방화벽, 격리 Wi-Fi 등)는 연결되지 않을 수 있습니다.

### Android 개발 모드 Vite HMR 연결

Vite는 `TAURI_DEV_HOST`를 사용해 Android가 접근하는 PC 주소와 HMR WebSocket 호스트를 일치시키도록 설정했습니다. 개발 서버 포트는 **1421**, 실제 펜 입력 포트는 **39871**로 서로 다릅니다. AdrenoVK 셰이더 경고는 별개로 처리해야 합니다.

### USB 연결 (개발용 ADB reverse)

PC에서 `adb devices`로 스마트폰을 확인한 후:

```powershell
adb reverse tcp:39871 tcp:39871
```

- PC GUI는 **USB / 로컬 전용** 모드로 시작.
- 휴대폰 PC 주소 입력란에 **`127.0.0.1`** 입력.
- USB의 데이터가 **ADB reverse**로 전달되므로 Wi-Fi 노출 없이 동작.
- USB 디버깅이 꺼지거나 폰을 재부팅하면 ADB reverse를 다시 실행해야 할 수 있음.

## Android 입력패드 전체화면 ON/OFF

- 연결 성공 시 기본적으로 **전체화면 ON**입니다. 가로 화면에서 **중앙 16:9 입력판과 좌우 조작 아이콘 영역**을 표시합니다.
- 오른쪽 사이드바의 **작은 축소 아이콘**으로 일반 화면으로 돌아오고, 일반 화면의 **전체화면 켜기** 버튼으로 다시 전환합니다.
- 선택한 ON/OFF 상태는 기기에 저장되어 다음 연결에서도 유지됩니다.
- 전체화면의 왼쪽/오른쪽 사이드바에 PC 오버레이 기능을 유지하므로 일반 설정 화면 없이 마우스/필기 전환, 색상/굵기/필압, 되돌리기/지우기/저장, PC 툴바 선택/위치 초기화 등을 조작할 수 있습니다.
- 중앙의 실제 캔버스만 입력 좌표 계산에 사용하므로 가로 21:9 기기 화면에서 16:9 PC로 전달할 때 종횡비 불일치를 줄입니다.
- 네이티브 Android 몰입형 모드에서 상태 표시줄과 내비게이션 버튼을 숨기고 전체화면 OFF 시 복원합니다. 시스템 제스처로 잠깐 표시될 수 있습니다.

## S펜 가로 방향·필압·PC 실시간 도구 동기화

- 휴대폰을 **가로로 회전**하면 Android MainActivity가 `fullSensor` 설정에 따라 화면 레이아웃을 실제로 회전합니다. **자동 모드에서는 화면 왼쪽이 PC의 왼쪽**으로 이동하며, 16:9 비율로 억지 변환하지 않습니다.
- 해당 Android 회전 설정은 `RUN_ANDROID_DEV.bat` 또는 `BUILD_ANDROID_DEBUG_APK.bat`에서 호출하는 `scripts/patch-android-manifest.ps1`이 생성된 MainActivity에 적용합니다. **앱을 다시 빌드/설치해야 적용됩니다.**
- 특별히 WebView가 세로 방향으로 고정되어 있는 경우 모바일 **일반 모드 → 펜 도구 → 좌표 방향**에서 왼쪽/오른쪽 90° 수동 보정을 사용할 수 있습니다. 정상 회전 시에는 반드시 `자동`으로 둡니다.
- Windows 화면 오른쪽 위에 작은 **PenStudy Ink Tools** 플로팅 창이 표시됩니다. 색상·펜 두께·필압 ON/OFF·되돌리기·전체 지우기·PNG 저장을 조작할 수 있습니다. 실제 필기 오버레이는 여전히 클릭을 통과시키므로 다른 프로그램을 클릭할 수 있습니다.
- PC GUI/플로팅 툴바/모바일의 펜 색상·굵기·필압 사용 여부가 WebSocket으로 실시간 동기화됩니다. 접속 시 PC 설정을 먼저 내려주며 모바일에서 변경한 값도 PC에 반영됩니다.
- **필압**: 모바일은 Android WebView의 S펜 PointerEvent.pressure (0~1)와 coalesced input sample을 전달합니다. PC가 압력에 따라 획 굵기를 그리며, **PC 필기 설정**에서 필압 사용과 감도를 조정할 수 있습니다.
- 실기기에서 필압이 달라지는지 보려면 모바일 전체화면을 끄고 일반 모드의 **현재 압력 %**가 약하게/강하게 눌렀을 때 변하는지 확인합니다. 특정 WebView/펌웨어가 항상 50%를 반환한다면 네이티브 MotionEvent 필압 브리지 개발이 추가로 필요합니다. 브라우저가 제공하지 않는 실제 하드웨어 압력을 임의로 만들어내지는 않습니다.
- PC 스크린샷 캡처 시 오버레이와 플로팅 툴바를 잠시 숨겼다가 복원합니다.

## 실시간 필기·호버 및 모바일 전체화면 시스템 바

- **PC 지연 개선**: WebSocket TCP_NODELAY, 여러 필압 샘플 묶음 전송, PC 오버레이의 캔버스 즉시 선분 렌더링. 반투명 오버레이에서 `requestAnimationFrame`이 지연될 수 있는 문제를 피합니다.
- **S펜 호버**: 갤럭시에서 화면에 닿기 전 전달되는 `pointermove` 중 `pointerType=pen` 입력을 받아 PC에 작은 포인터 표시. 펜이 입력 영역을 벗어나면 포인터를 숨깁니다. **Android WebView에서 hover 이벤트가 전달되는 기기에서만 작동합니다.**
- **모바일 전체화면 ON**: Android Tauri 네이티브 몰입형 플러그인으로 **하단 탐색 버튼/제스처 바 및 상단 상태바**를 숨기고 필기 영역을 넓힙니다. 연결 종료/전체화면 OFF 시 복원합니다. 가장자리 스와이프로 시스템 바를 일시 표시할 수 있습니다.
- **기존 회전 동작은 변경하지 않습니다.** 모바일 가로모드 진입 시 이미 정상 작동한다는 확인에 따라 `fullSensor` 설정을 그대로 유지합니다.
- 몰입형 모드는 Android 네이티브 변경이므로 앱을 다시 빌드해야 적용됩니다. PC는 Rust 및 데스크톱 Vite 코드를 다시 실행해야 합니다.
- 실제 지연/호버 지원은 Galaxy S24 Ultra 실기기에서 확인해야 하며 모바일에서도 지연된다면 Wi-Fi 간섭 및 디바이스 렌더링을 추가로 점검해야 합니다.

## Android 16:9 입력 영역 및 좌우 오버레이 툴바

- 갤럭시 S24 Ultra 등의 **가로 19.5:9/21:9 화면**에서 전체화면 ON 시, 중앙 필기·마우스 입력판을 **정확한 16:9 비율**로 맞추고 남는 왼쪽/오른쪽 공간을 오버레이 조작 도구 전용으로 사용합니다. 16:9보다 좁은 화면에서도 최소 52px의 좌우 조작 공간을 확보하도록 입력판을 줄입니다.
- **왼쪽**: Windows 마우스/필기 모드 전환, 마지막 필기 되돌리기, 전체 지우기, PC 화면 PNG 저장.
- **오른쪽**: 커스텀 펜 색상 선택, 펜 굵기 -/+, 필압 ON/OFF, PC 플로팅 툴바 선택/위치 초기화, 전체화면 종료.
- 입력 좌표는 **중앙의 실제 캔버스 경계만 기준**으로 정규화합니다. 측면 아이콘 영역에서 터치해도 필기/Windows 마우스 클릭 패킷을 전송하지 않습니다. 21:9 전체 화면 좌표를 억지로 16:9 PC에 늘리는 문제를 막습니다.
- 모바일 오른쪽의 이동 아이콘은 **PC 플로팅 툴바를 활성화**하고, 초기화 아이콘은 PC 툴바를 모니터 오른쪽 위로 되돌립니다. 툴바의 왼쪽 세로 점 손잡이를 PC 마우스 또는 모바일 S펜 마우스 모드로 끌어 위치를 바꿉니다. 전체 화면 필기 오버레이는 움직이거나 줄어들지 않습니다.
- **세로 화면**에서는 패드를 9:16으로 배치하고 도구를 상단/하단의 가로 아이콘 줄로 표시해 기존 기기 회전 동작을 유지합니다.
- 기존 PC 플로팅 툴바와 모바일 일반 화면은 유지됩니다. 모바일 전체화면 모드의 좌우 아이콘만 추가했습니다.

## S펜 마우스 제어 및 위치 이동 가능한 플로팅 툴바

- 연결 후 기본값은 **마우스 제어**: 모바일 S펜 호버(지원되는 기기)는 PC 실제 마우스 위치를 움직이고, 터치는 왼쪽 클릭, 누른 채 이동하면 드래그입니다. 인증된 로컬 세션에서만 입력을 받습니다.
- PC 툴바와 모바일에서 마우스/필기 모드를 전환할 수 있습니다. 기존 필기, 색상, 굵기, 필압은 그대로 유지합니다.
- **툴바 이동**: PC의 작은 플로팅 필기 툴바 맨 왼쪽 **세로 점 손잡이**를 마우스로 잡아 원하는 위치로 끌면 됩니다. 모바일 마우스 모드로도 손잡이를 누르고 드래그할 수 있습니다.
- PC 툴바의 복원 아이콘이나 모바일 사이드바의 툴바 초기화 아이콘을 누르면 오른쪽 위로 되돌아갑니다. 모바일 이동 아이콘은 툴바를 앞으로 가져옵니다.
- **투명한 필기 오버레이는 항상 주 모니터 전체를 덮으며 클릭을 통과**합니다. 과거 버전의 필기 오버레이 자체를 76%로 줄이던 편집 기능과 이상한 보라색 드래그 화면은 제거했습니다.
- PNG 저장 시 실제 필기 오버레이와 툴바를 잠시 숨긴 뒤 화면과 필기를 합성합니다.
- **PC 메인 창의 X 버튼을 누르면** 입력 서버(39871), 휴대폰 연결 및 보조 툴바·필기 창을 포함한 앱 전체가 종료되며, Windows에 눌려 있을 수 있는 가상 왼쪽 버튼도 해제합니다.
- **서버 중지 버튼**은 기존 리스너가 종료되어 39871 포트가 해제될 때까지 기다립니다. 서버를 다시 시작하면 세션 토큰이 새로 발급되므로 **모바일에서 새 QR을 스캔**해야 합니다.
- Wi-Fi 연결은 PC 앱의 **같은 Wi-Fi** 모드에서 서버를 시작해야 합니다. USB 연결은 PC 루프백 모드 + `adb reverse tcp:39871 tcp:39871` 후 모바일에서 `127.0.0.1`로 연결합니다. 로컬·신뢰 네트워크에서만 Windows 마우스 제어를 활성화하세요.

## 레이어별 그리기·지우기 / 별도 지우개 크기 / 독립 좌우 도구창

- **Photoshop 모드에서 그리기와 지우개는 모두 현재 선택한 레이어에만 작용**합니다. 다른 레이어에 그린 선을 덮거나 지우지 않습니다. 숨겨진 레이어에는 새 획이 입력되지 않습니다.
- **전체 지우기와 되돌리기도 선택한 레이어만 대상**입니다. 전체 지우기를 눌러도 다른 레이어의 선과 지우개 획은 그대로 유지됩니다. **지우기 직후 되돌리기**를 누르면 선택 레이어의 선이 복원됩니다. 일반(Photoshop OFF) 모드에서는 기존 전체 지우기 동작을 유지합니다.
- 모바일 입력판도 레이어별 투명 캔버스로 미리보기를 합성합니다. 표시/숨김/순서 변경을 즉시 반영하고, 해당 레이어에서 지우개를 쓰거나 되돌리기를 해도 다른 레이어를 손상시키지 않습니다.
- **지우개 굵기는 펜 굵기와 완전히 별도**로 동기화됩니다. 기본 **64px**, 범위 **4~512px**. PC 필기 설정의 **지우개 굵기** 슬라이더/숫자 입력, PC **오른쪽 툴바**의 지우개 슬라이더, 모바일 일반 화면 슬라이더 또는 전체화면 오른쪽 +/- 아이콘에서 변경할 수 있습니다.
- PC의 떠 있는 조작 툴바를 **좌측/우측 2개의 별도 Tauri 창**으로 나눴습니다. 좌측은 **마우스/필기, 펜/지우개, 되돌리기, 선택 레이어 지우기, PNG 저장**. 우측은 **색상, 펜/지우개 굵기, 필압, 브러시, Photoshop/PSD**. **각 창 맨 왼쪽 점 손잡이를 따로 드래그**할 수 있고 각 창의 복원 버튼은 해당 창만 제자리로 보냅니다.
- 모바일 16:9 입력판 **왼쪽/오른쪽 아이콘 바**도 독립적으로 움직일 수 있습니다. 각 바 맨 위 **점 손잡이를 S펜/손가락으로 위아래 드래그**하면 해당 바만 이동합니다. 위치는 기기에 저장되며, 손잡이를 두 번 누르면 해당 바가 가운데로 복원됩니다. 세로 화면에서는 가로 방향으로 움직일 수 있는 공간만큼 이동합니다.
- 모바일 좌우 아이콘의 PC 툴바 선택/초기화도 **해당 방향의 PC 툴바만** 대상으로 합니다. PC 창 위치는 사용 세션 중 유지되며 기본 위치로 언제든 복원 가능합니다.
- 기존 주 모니터 투명 필기 오버레이는 전체 화면과 클릭 통과 상태를 유지하며, PNG·PSD 저장 중에는 PC의 두 작은 툴바가 모두 캡처에서 제외됩니다.

## 모바일 입력판 배경색과 Photoshop 모드 (PSD)

- **모바일 입력판 기본 배경은 흰색**(`#FFFFFF`)입니다. 일반 화면의 **입력판 배경색** 또는 전체화면 오른쪽 배경색 아이콘에서 원하는 색을 선택할 수 있습니다. 기기에 저장되어 다음 실행에도 유지됩니다. 배경색은 *모바일의 입력판 표시만* 바꾸며 PC 투명 필기 오버레이의 클릭 통과와 PNG 캡처에는 영향을 주지 않습니다.
- **브러시 4종**: 일반 펜, 형광 마커(반투명/넓음), 연필(가는 질감), 에어브러시(부드러운 그라데이션). 모바일 일반 화면의 브러시 종류 선택, 전체화면 오른쪽 붓 아이콘(누를 때마다 변경), PC 필기 설정에서 바꿉니다. S펜 필압과 지우개 모드는 기존대로 유지됩니다.
- **Photoshop 레이어 모드**: 모바일 전체화면 오른쪽의 **레이어 아이콘** 또는 PC **필기 설정 → Photoshop 레이어 모드**에서 ON/OFF. 켜면 자동으로 필기 입력 모드로 전환됩니다.
- 레이어 목록은 **아래에서 위로 쌓이는 순서**를 따릅니다. 모바일 오른쪽 레이어 패널 또는 PC 필기 설정에서 **레이어 추가 / 선택 / 이름 변경 / 표시·숨김 / 위·아래 이동 / 삭제**를 지원합니다(최대 24개). 실제 획은 선택한 레이어에만 기록되며 레이어별 지우개가 다른 레이어의 픽셀을 손상시키지 않습니다.
- **PSD 저장**: Photoshop 모드를 켠 다음 모바일의 PSD 저장 아이콘, PC 필기 설정의 **레이어 포함 PSD 저장**, 또는 PC 툴바의 PSD 아이콘을 누릅니다. 저장 경로는 기존 PNG 저장 설정과 동일한 **사진/PenStudyCaptures** 또는 사용자 지정 출력 폴더입니다.
- 저장된 PSD는 **Windows 주 모니터 캡처를 최하단 'PC 화면' 이미지 레이어**, 그 위에 **S펜 레이어들을 이름·순서·표시 상태를 유지한 각각의 RGB 8비트 이미지 레이어**로 담습니다. PNG 파일의 이름만 변경하는 방식이 아닙니다. Photoshop에서 이미지 레이어별 편집이 가능하지만 *벡터 브러시 경로, Photoshop 원본 브러시 프리셋, 조정 레이어, 스마트 오브젝트*까지 생성하는 것은 아닙니다.
- PSD 또는 PNG 저장 후에는 필기와 레이어를 자동으로 지우지 않습니다. 화면을 비우려면 수동 지우기 버튼이나 단축키를 사용하세요.
- PSD 작성은 오픈소스 `ag-psd`(MIT)를 사용합니다. 소스를 처음 업데이트하면 **`npm install`**을 실행해 새 브라우저 PSD 라이브러리를 설치하세요. `npm test`의 PSD 왕복 테스트가 실제 레이어를 읽어 검증합니다.
- 파일 크기는 문서 해상도와 레이어 수에 따라 커질 수 있으므로 4K에서 레이어 수가 많다면 저장 시간이 길어질 수 있습니다. PSD/PSB 고급 포맷이나 16비트·32비트 문서는 이번 범위에서 지원하지 않습니다.

## 직접 지우개 및 사용자 지정 전역 단축키

- **S펜 직접 지우기**: 모바일 가로 전체화면 왼쪽의 **지우개 아이콘** 또는 일반 화면의 **펜/지우개 선택**, PC 플로팅 툴바나 PC 필기 설정에서 **지우개**를 선택합니다. 마우스 모드에서 지우개를 선택하면 자동으로 필기 모드로 전환합니다.
- 지우개 기본 지름은 **64px(PC 좌표)**이며 4~512px 범위에서 펜 굵기와 별도로 조절합니다. S펜으로 문지른 부분만 **현재 필기 레이어**에서 투명해집니다(`destination-out`). 화면이나 프로그램 배경을 흰색으로 칠하지 않으며 이전 필기를 부분적으로 지울 수 있습니다.
- 펜 획뿐 아니라 **지우개로 문지른 동작도 작업 기록에 쌓이므로**, 되돌리기 키를 누르면 마지막 지우개 작업이 취소되어 지워진 선이 다시 나타납니다. **PNG/PSD 저장은 필기를 지우지 않으며**, 지우기는 사용자 명령으로만 실행됩니다.
- **PC 환경설정 → 사용자 지정 전역 단축키**에서 전체/영역 PNG·PSD 저장, 펜·지우개·마우스 전환, 두께·색상·브러시, 필압, 레이어 동작, 툴바, 그림 프로그램 자동 연결 등 **26개 동작**에 단축키를 지정하거나 해제할 수 있습니다. 입력칸에서 키를 누르면 저장과 Windows 전역 단축키 재등록을 시도합니다.
- 기본 단축키는 **F9 전체 화면 PNG, Ctrl+Shift+1 드래그 영역 PNG, Ctrl+Shift+2 지정 영역 PNG, F7 되돌리기, F10 전체 지우기, F8 펜↔지우개 전환**입니다. 그 외 20개 동작은 기본 **미지정**입니다. 지원 범위는 F1~F12 단독 또는 Ctrl/Alt/Shift 조합, Ctrl 또는 Alt를 포함한 영문/숫자 키입니다.
- 충돌되는 조합이나 이미 다른 앱에서 등록한 전역 키는 적용하지 않고 오류를 표시합니다. 기존 키 등록은 최대한 복원합니다. 수정한 설정은 PC 로컬 저장소에 유지되어 다음 실행 시 복원됩니다.
- Windows 앱의 전역 단축키이므로 **다른 프로그램에 포커스가 있을 때도 동작**합니다. 해당 키를 다른 프로그램이 이미 사용 중인 경우 충돌 여부를 확인하세요.

### PNG 영역 캡처

- **드래그 영역 저장:** PC 저장 설정에서 드래그 영역 저장을 누르거나 `Ctrl+Shift+1`을 누르면, Windows 주 모니터 위에서 마우스로 영역을 지정할 수 있습니다. 마우스를 놓으면 해당 영역의 **PC 화면 + 필기**가 PNG로 저장됩니다. `Esc` 취소도 가능합니다.
- **고정 영역 저장:** PC 저장 설정에서 **고정 영역 지정**을 누르고 한 번 드래그해 저장한 다음, `Ctrl+Shift+2` 또는 지정 영역 저장 버튼을 누르면 같은 영역을 반복해서 캡처할 수 있습니다. **영역 변경 / 해제**도 지원합니다.
- 고정 영역은 앱 설정 디렉터리의 `capture-region.json`에 저장되어 앱을 다시 켜도 유지됩니다. 위치·크기는 화면 비율로 저장하므로 주 모니터 해상도 변경 시 비례하여 적용됩니다.
- 영역 선택 중에만 투명 필기 오버레이에서 PC 마우스를 받아들이고 두 개의 플로팅 툴바는 숨깁니다. 선택 또는 취소 이후 원래 클릭 통과 상태를 복원합니다.
- 기존 PNG 저장 폴더 설정은 그대로 사용합니다. **전체 화면·드래그 영역·고정 영역 PNG 모두 저장 후 필기가 유지**되며, 저장 설정의 자동 지우기 옵션은 제거되었습니다. PSD 저장도 기존 전체 레이어 방식으로 유지됩니다.

## 그림 프로그램 활성 창 자동 연결 및 오버레이 전역 단축키

- **필기 설정 → 그림 프로그램 자동 캔버스 연결**(기본 켜짐): Windows의 **현재 활성 창**이 Photoshop(`Photoshop.exe`), 그림판(`mspaint.exe`), Krita, Paint.NET, Clip Studio Paint 또는 PaintTool SAI이면, S펜의 필기 입력을 PenStudy 자체 오버레이 대신 **Windows 마우스 입력**으로 전달합니다. 단순히 프로그램이 실행되어 있다는 이유만으로 전환하지 않습니다.
- 대상 프로그램에서 먼저 **브러시를 선택**하고 화면의 **그 프로그램 캔버스 안에** 입력 위치를 맞춰 사용해야 합니다. 현재 구현은 전용 Photoshop 브러시 API/Windows Ink 가상 디지타이저가 아닌 OS `SendInput` 방식이므로 **필압·기울기 데이터는 그림 프로그램에 전달되지 않습니다.** 캔버스 영역 자동 감지나 임의의 앱과 플러그인 연동까지 보장하지 않습니다.
- 앱 창이 바뀌면 필기 중 누른 마우스 버튼을 놓아 다른 프로그램으로 드래그가 이어지지 않게 합니다. 미지원 앱이 활성화되면 PenStudy 오버레이에 필기하며, 자동 연결을 끄면 항상 기존 오버레이 동작으로 돌아옵니다. 마우스 모드는 기존의 Windows 마우스 제어를 그대로 유지합니다.
- PC 플로팅 **오른쪽 툴바의 커서 아이콘**이나 필기 설정에서 자동 연결을 켜거나 끌 수 있으며, **환경설정 → 사용자 지정 전역 단축키**에서 자동 연결 토글에도 단축키를 지정할 수 있습니다.
- 전역 단축키는 **26개 동작**(전체/영역/고정 PNG, PSD, 지우기, 실행 취소, 펜/지우개, 굵기 증감, 색상 순환, 필압, 브러시, 포토샵 모드, 레이어 추가·선택·표시, 툴바 초기화, 자동 연결 등)을 지원합니다. 기존 6개만 이전 기본 키로 유지하고, 나머지는 **미지정** 상태로 시작합니다. 필요할 때 단축키를 지정하고 X 버튼으로 해제할 수 있습니다.

## 실사용 순서

1. Windows PC에 교재/강의/PDF/브라우저 등을 표시한다.
2. 휴대폰 S펜으로 PenStudy Pad의 입력판에 필기한다. 화면 좌표와 압력은 PC에 전달되어 **주 모니터의 클릭 통과 투명 오버레이**에 표시된다.
3. 휴대폰에서 `PC 화면 저장` 또는 키보드 `F9`를 눌러 **현재 화면 + 손글씨**를 하나의 PNG로 저장한다.
4. `F7` = 마지막 획 취소, `F10` = 수동 지우기. **저장해도 필기는 그대로 유지**됩니다.
5. 기본 저장 위치는 `사진\PenStudyCaptures`이며 Windows GUI에서 변경 가능.

## 보안

- 클라우드, 계정 및 외부 서버 없음. 데이터는 PC와 휴대폰 사이 로컬로만 전송.
- Wi-Fi 모드는 사용자가 선택할 때만 0.0.0.0:39871에 바인딩; 기본은 127.0.0.1:39871.
- 토큰은 실행마다 새로 생성되고 재연결 시 필요. 서버 중지 시 무효화됨.
- **현재 전송은 `ws://` (TLS 없는 평문)**. 공용 Wi-Fi, 게스트 네트워크, 외부 인터넷 포트 포워딩 금지. 신뢰할 수 있는 집 LAN 또는 ADB USB 사용.
- 원격 클라이언트가 인증 후 화면 저장을 요청할 수 있으므로 토큰을 제3자에게 공유하지 마세요.
- Wi-Fi 연결에서 서버를 중지하면 현재 사용 중인 세션도 끊어집니다.
